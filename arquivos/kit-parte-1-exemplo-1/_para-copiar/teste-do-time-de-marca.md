# O teste do time de marca · prática 4b

Três mensagens, numa conversa nova dentro do projeto "Time de marca", uma de cada vez.

1. O primeiro teste:

```
quem está aqui?
```

2. Um caso que cai em dois especialistas ao mesmo tempo:

```
Tenho uma escola de cursos livres em Fortaleza há oito anos: Excel, oratória e gestão, turmas à noite. Os concorrentes dizem o mesmo que eu: professor experiente, certificado e preço justo. Ninguém lembra do nosso nome. Por onde eu começo?
```

3. Depois da resposta assinada:

```
Agora quero ouvir o outro lado.
```
