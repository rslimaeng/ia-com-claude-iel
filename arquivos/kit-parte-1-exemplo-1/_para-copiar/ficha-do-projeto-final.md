# A ficha do seu projeto final

Uma tarefa real sua, que você vai construir nos quatro encontros. Escolha a mais chata, não a mais importante.

| Campo | A sua resposta |
|---|---|
| 1 · A tarefa, em uma frase | |
| 2 · Quantas vezes ela volta por mês (número, não advérbio) | |
| 3 · O que chega para você (a entrada: arquivo, e-mail, planilha) | |
| 4 · Os passos que você faz hoje, com o tempo de cada um | |
| 5 · O que sai pronto (a saída) e quem recebe | |
| 6 · Como você sabe que ficou certo (o critério) | |
| 7 · Em qual caixa o material cai: entra, entra sem identificação, ou não entra | |

**A régua:** volta quatro vezes ou mais por mês, e o critério não muda? Então vale um projeto. Uma vez por mês ou menos raramente paga.
